## Trust boundaries

| Boundary | Description |
|----------|-------------|
| Skill → Bash | Skill text instructs Claude to run `node /absolute/.../scripts/pmacro.cjs`; malicious repo could ship harmful script — user trust is the repo. |
| `~/.claude/settings.json` read | Status command reads to detect hook; treat as untrusted JSON; never eval. |
| Macro values | CRUD-01 user input; store as string; no shell interpolation when writing JSON. |

## STRIDE register

| ID | Category | Component | Disposition | Mitigation |
|----|----------|-----------|-------------|------------|
| T-04-01 | I | `settings.json` parse | mitigate | JSON.parse in try/catch; on failure report “unknown” hook state. |
| T-04-02 | E | CLI stderr | mitigate | Print user-readable errors to stderr; exit non-zero for CLI failures (skills show output). Hook remains separate (always 0). |
| T-04-03 | T | Overlong tag/value | mitigate | Enforce D-02 on tag; optional max value length (e.g. 1MB) to avoid OOM — document constant in `scripts/pmacro.cjs`. |
| T-04-04 | S | Path injection | mitigate | Skills must pass repo **absolute** path from a known `REPO_ROOT` variable in SKILL template filled at copy time **by user** OR use `AskUserQuestion` to ask once for repo root — document: “set PMACROS_REPO in skill or replace placeholder”. Prefer SKILL instructing: run from repo root using `pwd` in session. |
| T-04-05 | D | N/A | accept | Local CLI. |
| T-04-06 | R | N/A | accept | Local CLI. |
