# Plan 02 — Shared library: paths, atomic JSON store, expansion, JSONL error log

## Objective

Implement Node **stdlib-only** modules used by the hook and CLI: resolved paths under `~/.claude/pmacros/`, atomic read/write of `macros.json` with `schemaVersion`, `{{tag}}` expansion per D-02 regex, and `hook-errors.log` JSONL appends per **D-12**.

<threat_model>
## Trust boundaries

| Boundary | Description |
|----------|-------------|
| Disk (`~/.claude/pmacros/`) | User-owned; treat file contents as untrusted input when parsing JSON. |
| Log file | Append-only JSONL; must not leak macro **values** in error entries unless explicitly required (prefer tag + message only for misses). |

## STRIDE register

| ID | Category | Component | Disposition | Mitigation |
|----|----------|-----------|-------------|------------|
| T-02-01 | T | `macros.json` | mitigate | Parse inside try/catch; on invalid JSON log error line and surface failure to caller; never throw uncaught from lib entrypoints used by hook. |
| T-02-02 | I | Tampered `macros.json` | mitigate | Validate shape: `schemaVersion` number, `macros` object, each value has `value` string; ignore unknown fields; reject non-string `value` for expansion. |
| T-02-03 | E | Atomic write | mitigate | Write temp under same directory as `macros.json`; `fs.renameSync` overwrite (D-12 path: `~/.claude/pmacros`). |
| T-02-04 | S | Path traversal in tag names | mitigate | Tag regex must only allow `[a-z0-9-]{1,32}`; refuse writes if tag invalid (D-02). |
| T-02-05 | D | Error log growth | accept | D-13 deferred; document unbounded growth in code comment only. |
| T-02-06 | R | N/A | accept | Local tool. |
</threat_model>
