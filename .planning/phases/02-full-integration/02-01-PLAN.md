# Plan 01 — Project/user merge: paths, safe reads, hook expansion

## Objective

Implement **STOR-02**: load project macros from `.claude/pmacros/macros.json` (relative to resolved project root) and merge with user `~/.claude/pmacros/macros.json` so **project keys override user** on collision. Invalid or missing JSON on **one** side must not prevent the other side from loading (CONTEXT **D-01**). Update `UserPromptSubmit` to expand using the merged map. Resolution: optional workspace fields on hook stdin JSON, else `process.cwd()` (**D-02**).
